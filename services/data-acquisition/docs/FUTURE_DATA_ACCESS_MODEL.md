# Future Data Access Model (deferred from v0.19 UI)

The commercial/service model is intentionally **not part of the current Data Acquisition operational UI**.
The following concepts are retained only as future architecture requirements:

- Customer
- Data Asset / Data Product
- Entitlement by customer, time range, fields/scope and usage rights
- Historical access vs ongoing access
- Download and Q2D-use permission
- Subscription / shared acquisition pricing
- Credit ledger for reusable/shared acquisition economics

Current development priority: source discovery, feasibility/exploration, audit, approval, acquisition, recurring monitoring, repository integrity and visibility.
